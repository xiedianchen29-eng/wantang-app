## 仓库约定

- 默认分支：`main`
- 每项工作先建立 Issue，再在独立分支中完成。
- 通过 Pull Request 审核后合并到 `main`。
- 不向仓库提交密码、API 密钥、支付密钥、证书或用户隐私数据。
