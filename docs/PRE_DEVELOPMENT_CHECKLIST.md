# 开发前检查清单

在开始编写 App 代码前，应完成或明确以下事项。

## 产品范围

- [ ] 明确目标用户
- [ ] 确定第一版是品牌展示版还是商城版
- [ ] 列出第一版必须包含的功能
- [ ] 列出明确不在第一版实现的功能
- [ ] 为主要功能写出可验证的完成标准

## 页面和交互

- [ ] 列出全部页面
- [ ] 确定每个按钮的跳转目标
- [ ] 补全加载、空白、错误和断网状态
- [ ] 确定轮播、返回、滚动和底部导航行为
- [ ] 检查最小字号和点击区域

## 内容与素材

- [ ] 确认品牌 Logo 和商品图的高清原文件
- [ ] 确认图片、字体和文案的商业使用授权
- [ ] 建立素材命名规则
- [ ] 准备隐私政策、用户协议和客服信息

## 技术与数据

- [ ] 确定支持 iOS、Android 或两者
- [ ] 确定原生开发或跨平台开发
- [ ] 确定是否需要服务器、数据库和后台管理
- [ ] 确定登录、支付、订单、物流和消息通知需求
- [ ] 确定测试、统计、监控和备份方案

## 发布与维护

- [ ] 确认目标应用市场及开发者账号
- [ ] 确认上线地区对应的合规要求
- [ ] 准备测试设备和测试账号
- [ ] 确定版本发布、故障处理和日常维护负责人
