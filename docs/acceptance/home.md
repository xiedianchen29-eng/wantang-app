# 首页验收标准（第一阶段 V1.0）

> 状态：静态首页、第一阶段按钮规则和轮播规则已确认。
> Figma 来源：文件 `碗糖时序`，首页节点 `1:202`。
> 基准画布：宽 370 px，高 822 px。
> 本文用于第一阶段模拟数据开发，不包含真实支付、购物车和服务器接口。

## 1. 本轮可以验收的内容

### 1.1 页面整体

- [ ] 页面在安卓手机上可正常打开，无白屏、崩溃、横向溢出。
- [ ] 以 370 × 822 为视觉基准；窄屏等比缩放，宽屏内容最大宽度 430 px 并居中。
- [ ] 正确避开顶部状态栏、刘海和底部系统手势区域。
- [ ] 页面底色接近 Figma 的暖白色 `#FEFAEE`。
- [ ] 主内容可以纵向滚动；底部导航固定在可见区域。
- [ ] Figma 可见图片全部下载到项目本地，不使用会过期的 Figma 临时链接。
- [ ] 不用相似图片、色块或手绘图标替换 Figma 中的正式资源。

### 1.2 模块顺序

页面从上到下必须是：

1. 顶部红糖主视觉。
2. 九个业务入口。
3. 故事轮播。
4. 今日暖意商品区。
5. 底部五项导航。

模块顺序不能调整，也不能漏掉占位。

### 1.3 顶部主视觉

- [ ] 显示红糖产品主图、品牌标识和暖棕色背景效果。
- [ ] 主要文字包含“万华食品”“巧家红糖”。
- [ ] 主标语为“一碗古法糖，暖暖每一天”。
- [ ] 辅助说明包含“源自金沙江畔，沿用三百年古法熬制”“零添加的小碗红糖”。
- [ ] 主视觉与下方暖白内容面板衔接自然，顶部圆角、阴影和叠层关系与 Figma 一致。
- [ ] 状态栏图标在背景上清楚可见。

### 1.4 九个业务入口

- [ ] 第一行依次为：红糖食谱、暖饮礼包、品牌故事、节气专栏、品牌周边。
- [ ] 第二行依次为：特价好物、原料溯源、企业合作、红糖工艺。
- [ ] 每个入口都使用 Figma 对应图标，图标、文字和间距一致。
- [ ] 入口的可点击区域不得小于 44 × 44 px。
- [ ] 点击未开发入口时显示“功能规划中”，暂不制作按压动效。

### 1.5 故事轮播

- [ ] 标题为“故事轮播”。
- [ ] 右侧显示“故事详情”及方向提示，本阶段不跳转。
- [ ] 显示 Figma 对应故事图片，不得拉伸或裁掉主要人物和锅灶内容。
- [ ] 下方显示三枚页码圆点，当前项为深红色，非当前项为灰棕色。
- [ ] 轮播每 4 秒自动切换，同时支持手动左右滑动。
- [ ] 圆点只显示当前位置，不允许点击切换。

### 1.6 今日暖意

- [ ] 标题为“今日暖意”。
- [ ] 右侧显示“查看全部”及方向提示。
- [ ] 首屏可见三张商品卡片，卡片使用深棕色背景、圆角和 Figma 商品图片。
- [ ] 商品名称、标签、价格和右下角圆形加号位置与 Figma 一致。
- [ ] 示例商品包含“姜枣红糖暖饮”，价格展示使用“¥”。
- [ ] 商品数据第一阶段来自项目内的模拟数据文件，不直接散落在页面代码中。
- [ ] “查看全部”和商品卡片本阶段不跳转；加号只加入模拟购物车，不跳转页面。

### 1.7 底部导航

- [ ] 依次显示：首页、手札、礼事、风物、我的。
- [ ] “首页”为选中状态，颜色和视觉重量明显区别于未选中项。
- [ ] 图标和文字均来自 Figma 对应资源与样式。
- [ ] 导航避开安卓底部手势条，不被遮挡。
- [ ] 再次点击首页不回到顶部；其余未开发入口显示“功能规划中”。

### 1.8 颜色与文字

- [ ] 页面主色使用暖白、红棕、深棕和琥珀棕；初始色值参考：
  - 暖白：`#FEFAEE`
  - 商品卡深棕：`#774733`
  - 强调红棕：`#731813`
  - 主视觉琥珀棕：`#BA6F00`
- [ ] Figma 中使用了等线、华文中宋、微软雅黑等字体；安卓未必自带这些字体。
- [ ] 开发前需要确定：由 Figma/品牌方提供可使用的字体文件，或采用安卓可用的近似字体。
- [ ] 在字体方案确定前，以字号、字重、行高和整体气质接近为阶段验收标准，不承诺逐字像素完全一致。

## 2. 已确认的按钮与交互

| 位置 | 第一阶段行为 |
|---|---|
| 九个业务入口 | 点击后显示“功能规划中” |
| 故事详情 | 只展示文字，本阶段不跳转 |
| 故事轮播 | 自动轮播并支持手动滑动，圆点不可点击 |
| 查看全部 | 只展示文字，本阶段不跳转 |
| 商品卡片 | 本阶段不跳转 |
| 商品加号 | 加入模拟购物车，不跳转页面 |
| 首页导航 | 再次点击不回到页面顶部 |
| 手札、礼事、风物、我的 | 未开发时显示“功能规划中” |
| 按压反馈 | 本阶段不制作额外按压动效 |
| 安卓状态栏 | 使用系统原生状态栏样式 |

## 3. 后续版本补充的验收项

加载、失败、空数据和权限说明页面完成设计后，需要补齐：

- [ ] 点击前的默认状态。
- [ ] 手指按下时的反馈状态。
- [ ] 点击成功后的页面或结果。
- [ ] 连续点击时是否防重复触发。
- [ ] 加载中的显示方式。
- [ ] 操作失败时的提示文字和重试入口。
- [ ] 没有数据时的空状态。
- [ ] 返回上一页后的页面位置和数据是否保留。
- [ ] TalkBack 可读名称和至少 44 × 44 px 的点击区域。

## 4. 第一阶段验收方式

1. 使用安卓实体手机和 Expo Go 打开项目。
2. 与 Figma 370 × 822 首页截图并排对照。
3. 逐项勾选本文件中“本轮可以验收的内容”。
4. 按本文件第二节逐项验证按钮与轮播行为。
5. 视觉、文字、资源和稳定性全部通过后，首页静态版才算完成。
